# Contributing to trackedbot

The following is a set of guidelines for contributing to **trackedbot** and its package, which are hosted in the [trackedbot](https://github.com/vroncevic/trackedbot) on GitHub. These are mostly guidelines, not rules. Use your best judgment, and feel free to propose changes to this document in a pull request.

## Code of Conduct

**trackedbot** project and everyone participating in it is governed by the [trackedbot code of conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code. Please report unacceptable behavior to [trackedbot](mailto:elektron.ronca@gmail.com).
